# Evolução da IA

Um oráculo interativo que estima a evolução da Inteligência Artificial até 2070, com base em modelos probabilísticos (Monte Carlo) e cenários otimistas/pessimistas.

🌐 Aceda ao site: https://evolucao-da-ia.onrender.com

**Nota:** As previsões são especulativas, não profecias.
